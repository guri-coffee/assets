# フィールド仕様書: スタイライズド和風ナイトビレッジ（忍者の城下町）

参考画像をもとにした、販売用環境アセットの制作仕様。全体計画は `unity-asset-store-sales-plan.md` を参照。

## 0. 参考画像の分析

- **構図**: 見下ろし（アイソメ風）視点。多段の岩の台地の上に町が広がり、最上段に天守（城）が鎮座するピラミッド型の構成
- **時間帯・ムード**: 夜。藍色〜紫の空気感に、建物の暖色（オレンジ）の灯りとネオンパープルの発光体が対比するカラーパレット
- **主要要素**: 和風城（天守）、瓦屋根の町屋群、赤い太鼓橋と欄干、大鳥居、石垣・石段、水路と滝、水車、桜、灯籠・提灯、幟（のぼり）、ホログラム看板、小型飛行ドローン・飛行船
- **スタイル**: ローポリ＋手描き風テクスチャのスタイライズド調。エミッシブ（発光）マテリアルを多用

### 権利面の対応（ストア審査対策・対応方針確定）

参考画像には NinjaDAO / NFT 系のロゴ・文言が含まれるが、**第三者IP・ブランドを含むアセットは Asset Store の審査で差し戻し・削除対象**。本アセットでは以下のオリジナルブランドに全面置換する。

- **ブランド名: TSUKIKAGE（月影の里）** — 架空の里の名前。ストア商品名にも使用する
- **紋章**: 三日月と桜の花弁5枚を組み合わせたオリジナルの「月桜紋」。参考画像の手裏剣型紋章は使用しない
- **看板・幟の文言**: 「月影の里」「宿」「茶屋」「湯」など一般名詞のみ。NFT / STAKE / DAO 等の文言は一切使用しない
- **ホログラム看板**: 差し替え可能なテクスチャスロットとして実装（購入者が自作ロゴを入れられる = 審査対策と同時にセールスポイント）

## 1. アセット構成（モジュラーキット）

| キット | 内容 | 目安点数 |
|---|---|---|
| 地形・岩 | 段丘用の崖・岩壁モジュール、石垣、石段、岩（大中小）、浮島風の土台 | 30–40 |
| 城キット | 天守の階層パーツ（土台/中層/最上層/屋根/鯱）、門、櫓 | 25–35 |
| 町屋キット | 壁・屋根・柱・縁側・格子窓のモジュール＋組み立て済みプレハブ（家屋5–8種） | 40–60 |
| 橋・鳥居 | 太鼓橋（分割パーツ）、平橋、欄干、大小の鳥居 | 15–20 |
| プロップ | 灯籠、提灯、幟、看板、水車、樽、木箱、屋台、小舟、ベンチ | 40–60 |
| 植生 | 桜（3種）、松（2–3種）、低木、竹、苔むした岩 | 15–20 |
| 水まわり | 水面用メッシュ、滝、水路パーツ | 5–10 |
| ネオン・SF小物（差別化要素） | ホログラム看板（テクスチャ差し替え可）、発光クリスタル、ドローン、小型飛行船 | 10–15 |

合計 180–260 プレハブ規模。競合（KINGDOM 約1,600点、参考アセット $59.99）に対し、点数ではなく「夜景ライティング完成品」と「和風×ネオンの独自性」で勝負する。

## 2. アートディレクション

- **ポリゴン**: ローポリ〜ミッドポリ。プロップ 300–2,000 tris、建物 2,000–10,000 tris 目安
- **テクスチャ**: 手描き風。共有アトラス化（環境1枚＋建物1枚＋プロップ1枚など）でドローコール削減
- **パレット**: ベース `#2b2d5e`（夜の藍）/ 暖色光 `#ffb347` / ネオン `#a06bff`・`#6bd9ff` / 屋根 `#2f3542` / 木部 `#8b4a2f` / 桜 `#f2a6c0`
- **発光**: 窓・提灯・ネオンはエミッシブマテリアル＋Bloom前提でオーサリング

## 3. Unity 実装要件

- **エディタ**: Unity 2021.3 LTS 以降（提出時の最低要件はガイドライン再確認）
- **パイプライン**: URP を第一対応。Built-in 用マテリアルを同梱、HDRP は余力があれば
- **ライティング**: 夜景デモシーンは Baked + Light Probes。主要光源（提灯・窓）はエミッシブ＋少数のリアルタイムポイントライトで演出
- **ポストプロセス**: Bloom / Color Grading / Vignette のプロファイル同梱（この画像の雰囲気の8割はここで決まる）
- **シェーダー**: Shader Graph で水面（うねり＋泡）、滝（スクロール）、ホログラム（走査線＋点滅）を作成
- **VFX**: 滝しぶき、霧（下層の雲海）、桜の花びら、ホタル風パーティクル
- **デモシーン**: 参考画像の構図を再現した完成シーンを1つ＋アセット一覧シーン1つ。カメラはアイソメ風の固定アングルサンプル付き

## 4. 制作順序

1. **ブロックアウト**: ProBuilder 等で段丘＋城＋町の配置をグレーボックスで確定（構図が命）
2. 地形・岩キット → 町屋キット → 城キット の順にモデリング（使用頻度が高い順）
3. 橋・鳥居・プロップ・植生
4. シェーダー・VFX・ライティング・ポストプロセス
5. デモシーン仕上げ → スクリーンショット/動画撮影（ストアページ素材を兼ねる）

## 5. ストア展開

- **カテゴリ**: 3D > Environments > Fantasy（和風×ネオンのスタイライズドは Fantasy が妥当。純和風リアル調に振るなら Historic）
- **タイトル案**: "TSUKIKAGE – Stylized Japanese Night Village"（検索語: japanese, ninja, village, stylized, night, neon を名前・説明に自然に含める）
- **価格**: 初回パックとして $39.99–$49.99、セール時 30–50% オフ想定
- **シリーズ展開**: 昼バージョン用ライティングプリセット → 内装パック → キャラクター、と拡張していく（計画書の長期戦略に対応）
