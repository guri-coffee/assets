# Color Palette

**正: CryptoNinjaアートディレクションガイドv0.1（2026-07-23確定）**

## メインカラー（世界の基調）

| 役割 | 色 |
|---|---|
| 基調1 | 藍色（indigo blue） |
| 基調2 | 墨黒（ink black） |
| 基調3 | 月光の白（moonlight white） |
| 基調4 | 紺（navy） |

## アクセントカラー

金 / 深紅 / 翠（エメラルドグリーン） / 紫

## エフェクトカラー

シアン / 淡い青白発光（ホログラム・札・光る鳥居・家紋）

## 光の対比ルール（最重要）

**提灯の暖色オレンジ** vs **ホログラムの冷たいシアン発光** — この対比が画面の要。
月光（白〜青白）が全体を包む。

## 運用

- 全画像生成は `tools/gen_image.py` の STYLE_BASE 経由（パレット焼き込み済み）
- Unityのライティング・ポストプロセスもこのパレットに寄せる
- HEX値は最初の本番アセットのカラーピックで確定させて、ここに追記する
